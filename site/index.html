Diseñada para leer rápido sin estorbar

Cada detalle está optimizado para documentos largos, artículos técnicos, PDFs y respuestas en streaming.

Motor neuronal local (Piper WASM)

Ejecuta modelos VITS en WebAssembly con onnxruntime-web y caché local en Cache Storage para sintetizar audio 100 % offline.

Streaming procedural O(1)

Fragmenta textos largos bajo demanda con rampa rápida de apertura (48 → 175 caracteres) y pre-síntesis paralela de los siguientes fragmentos.

Auto-lectura acoplable en 4 esquinas

Minimízala a una discreta línea lateral de 4×32 px o arrástrala a cualquier esquina sin tapar vídeos ni documentos.

Verbalización matemática inteligente

Pronuncia comparaciones, raíces, potencias, fracciones, notación científica, monedas y unidades en los 6 idiomas soportados.

Google Docs, PDFs y Gemini

Soporta selección en canvas de Google Docs, lectores PDF nativos vía menú contextual, Shadow DOM, iframes y streaming en Gemini.

Velocidad natural y tema en vivo

Ajusta la velocidad de 0.75x a 2.0x conservando el timbre humano natural y personaliza el color de la interfaz al instante.

Instalación gratuita

ReadFlow es 100 % gratuito y de código abierto (MIT). Descarga los paquetes ZIP listos para usar desde GitHub Releases o compila directamente desde el código fuente.

Descargar última versión (ZIP Chrome / Firefox)

Chrome, Brave, Edge, Opera y Vivaldi

  1. Clona el repositorio y ejecuta npm install && npm run build.
  2. Abre chrome://extensions y activa Modo de desarrollador.
  3. Pulsa Cargar descomprimida y selecciona dist/chrome.

Firefox, Zen Browser, LibreWolf y Floorp

  1. Ejecuta npm install && npm run build.
  2. Abre about:debugging#/runtime/this-firefox.
  3. Pulsa Cargar complemento temporal... y elige dist/firefox/manifest.json.
